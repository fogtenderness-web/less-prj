# less-prj

## Описание
Библиотека для обработки банковских данных: маскировка карт и счетов, фильтрация и сортировка транзакций, генераторы, логирование, конвертация валют.

## Модули

### `processing.py` — обработка транзакций
Функции для фильтрации и сортировки списка транзакций:

- **`filter_by_state(data, state='EXECUTED')`** — фильтрация по статусу
- **`sort_by_date(data, reverse=True)`** — сортировка по дате (от новых к старым)

### `masks.py` — маскировка номеров
- **`get_mask_card_number(card_number)`** — маскировка карты: `1234 56** **** 5678`
- **`get_mask_account(account_number)`** — маскировка счета: `**7890`

### `widget.py` — расширенные функции
- **`mask_account_card(input_string)`** — автоопределение карты или счета с маскировкой
- **`get_date(date_string)`** — преобразование ISO даты в формат `ДД.ММ.ГГГГ`

### `generators.py` — генераторы и итераторы
- **`filter_by_currency(transactions, currency='USD')`** — итератор, возвращающий транзакции с заданной валютой.
- **`transaction_descriptions(transactions)`** — итератор, выдающий описания операций по очереди.
- **`card_number_generator(start, end)`** — генерирует номера банковских карт в заданном диапазоне (формат `XXXX XXXX XXXX XXXX`).

### `decorators.py` — декораторы для логирования (новый модуль)
- **`log(filename=None)`** — декоратор, логирующий вызов функции (начало, конец, результат или ошибку).
  - Если `filename` задан, логи пишутся в файл; иначе — в консоль.
  - Логирование включает имя функции, аргументы, результат или тип ошибки.

### `utils.py` — загрузка данных из JSON
- **`load_transactions(file_path)`** — загружает список транзакций из JSON-файла.
  - Возвращает список словарей.
  - При любых ошибках (файл не найден, пустой, невалидный JSON, не список) возвращает пустой список.

### `uexternal_api.py` — конвертация валют через внешний API
- **`convert_currency(amount, from_currency, to_currency='RUB')`** — Конвертирует сумму из одной валюты в другую, используя Exchange Rates Data API.
  - Требуется наличие API-ключа в переменной окружения `API_KEY`.
  - При ошибках сети или некорректном ответе выбрасывает `ConnectionError` или `ValueError`

## Цель проекта

Предоставить простые утилиты для:
- Фильтрации и сортировки транзакций по статусу и дате
- Безопасного отображения номеров карт и счетов (маскировка)
- Форматирования банковских данных для вывода

**Целевая аудитория:** разработчики, аналитики данных, финансовые специалисты.

## Установка

Склонируйте репозиторий:

git clone https://github.com/fogtenderness-web/less-prj.git
cd less-prj

**Требования:**
* Python 3.6 или выше.
* Стандартная библиотека Python (дополнительные пакеты не требуются).
