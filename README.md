# less-prj

## Описание
Библиотека для обработки банковских данных: маскировка карт и счетов, фильтрация и сортировка транзакций.

## Модули

### `processing.py` — обработка транзакций
Функции для фильтрации и сортировки списка транзакций:

- **`filter_by_state(data, state='EXECUTED')`** — фильтрация по статусу
- **`sort_by_date(data, reverse=True)`** — сортировка по дате (от новых к старым)

### `masks.py` — маскировка номеров
- **`get_mask_card_number(card_number)`** — маскировка карты: `1234 56** **** 5678`
- **`get_mask_account(account_number)`** — маскировка счета: `**7890`

### `widget.py` — расширенные функции
- **`mask_account_card(input_string)`** — автоопределение карты или счета с маскировкой
- **`get_date(date_string)`** — преобразование ISO даты в формат `ДД.ММ.ГГГГ`

## Цель проекта

Предоставить простые утилиты для:
- Фильтрации и сортировки транзакций по статусу и дате
- Безопасного отображения номеров карт и счетов (маскировка)
- Форматирования банковских данных для вывода

**Целевая аудитория:** разработчики, аналитики данных, финансовые специалисты.

## Установка

Склонируйте репозиторий:

git clone https://github.com/fogtenderness-web/less-prj.git
cd less-prj

**Требования:**
* Python 3.6 или выше.
* Стандартная библиотека Python (дополнительные пакеты не требуются).
