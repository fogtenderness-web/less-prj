# Модуль processing: обработка и фильтрация транзакций

Библиотека для фильтрации и сортировки финансовых транзакций по состоянию и дате.

## Цель проекта

Модуль `processing` предоставляет простые и удобные функции для работы со списками транзакций

* **Фильтрация** по статусу транзакции (`filter_by_state`).
* **Сортировка** по дате в прямом и обратном порядке (`sort_by_date`).

**Целевая аудитория:** разработчики, аналитики данных, финансовые специалисты, работающие с наборами транзакционных данных.

## Установка

Модуль не требует отдельной установки — достаточно сохранить файл `processing.py` в директории вашего проекта.

**Требования:**
* Python 3.6 или выше.
* Стандартная библиотека Python (дополнительные пакеты не требуются).
